# Kupo Skribbl website

The public landing page at https://cloudesh.github.io/ for Kupo Skribbl / Kupopop.

The plugin and its source remain at https://github.com/cloudesh/kupopop.

GitHub Pages publishes the root of the `main` branch as a static site. Keep the
Google ownership-verification HTML file at the published root, including after
verification. The site uses no analytics or external scripts.

The artwork is reused from the original Kupopop project. The plugin screenshots
were supplied by the owner. See `LICENSE`.

`index.html` contains the complete player-facing content, installation instructions
and JSON-LD metadata. `assets/site.css` provides the responsive paper-and-pastel
layout; `assets/site.js` progressively enables the repository copy button. All
content and the repository address remain available without JavaScript. Live
version and download badges are served by Shields.io; downloads are not unique
players.

Preserve the canonical homepage URL, verification file, `robots.txt` and sitemap.
Keep search descriptions accurate, and never add invented ratings or reviews.

Keep the writing direct: explain the game, installation and privacy without
marketing slogans or repeated search phrases. Decorative details use simple
ink outlines and uneven paper edges. Do not restore the starburst symbols.
